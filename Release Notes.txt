💬 Commentaries:

Housekeeping pass aligning this module's plumbing with the IAM permissions-domain simplification
(IAM v1.3.0). No change to who can access the endpoints.

---

🔧 Changed:

    ▸ The init-time requirement check now uses `ModsManager::modExists('iam')` instead of the
      `modcontrol/control` service. Per-user inline authentication on the notification, push and
      chat endpoints is unchanged; this module defines no entity-level permission tags.
